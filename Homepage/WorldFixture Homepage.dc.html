HOW IT WORKS

Your app talks to real interfaces. Nothing is mocked in your code.

A Slack client calls Slack-shaped APIs. Mail uses SMTP and IMAP. Sign-in is a real OAuth redirect. Your own Postgres and MySQL are seeded from the same world artifact, so the names match everywhere.

POINT YOUR APP AT IT
$ worldfixture env --export
SLACK_BASE_URL=http://localhost:4003
SLACK_TOKEN=xoxb-maya
IMAP_HOST=localhost:1143
SMTP_HOST=localhost:2525
GITHUB_API_URL=http://localhost:4004
STRIPE_API_BASE=http://localhost:4013
S3_ENDPOINT=http://localhost:8333
DATABASE_URL=postgres://localhost:5432/northstar
MYSQL_URL=mysql://localhost:3306/northstar
$ npm run dev
No SDK to install and no code to change. Your application database is seeded too: the customer row in Postgres is the customer in Stripe and the person in #release.
